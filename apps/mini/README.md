# Mini App

Remote de Module Federation. Expone `./App` para que el Host lo importe como `miniApp/App`.

Sirve el contenedor federado:

```sh
npm start
```

También puedes instalarla y ejecutarla como una app React Native normal (`npm run ios` / `npm run android`) para desarrollarla aislada.

La guía completa está en el [README de la raíz](../../README.md).
