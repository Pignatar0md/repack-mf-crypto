# Host App

Contenedor nativo de este ejemplo de micro-frontends.

Arranca el servidor de Re.Pack:

```sh
npm start
```

Luego, desde otro terminal, lanza iOS o Android:

```sh
npm run ios
# o
npm run android
```

El Mini App tiene que estar sirviendo en el puerto **8082** para que la pantalla federada cargue.

La guía completa está en el [README de la raíz](../../README.md).
